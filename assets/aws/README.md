# Official AWS architecture icons

Selected unmodified PNGs from the31July2026 AWS architecture icon package, downloaded from the [official AWS icon page](https://aws.amazon.com/architecture/icons/). That page permits use of its assets for architecture diagrams. These assets are AWS's, not original group artwork. The manifest records original archive paths and SHA256 values; the source ZIP is kept only in ignored local temporary storage.

Package URL: https://d1.awsstatic.com/onedam/marketing-channels/website/public/shared/architecture-icon-release/Icon-package_07312026.5846e92413caa21490223536cc97f1269e44fa92.zip

The PDF uses vector text/lines and these PNG icons. Edit the layout through `scripts/build_architecture_pdf.py`, preserving correct service meaning and attribution.
